# 하이탑·케이탑 기본자료 함께 보기

케이탑으로 로그인하면 상가·택지·주거 자료보기에서 하이탑 기본자료를 함께 조회합니다. 공유 자료에는 `공유 기본자료` 표시가 붙습니다. 새 하이탑 자료는 페이지 새로고침으로 조회합니다.

공유 범위: 자료명·분류, 주소·면적·건축 기본정보, 호실·층·면적·도면 좌표, 평면도, 이름으로 구분한 단지/동호수 배치도, 택지 원본 도면·필지 기본정보.

공유 제외: 하이탑 고객 테이블, 소유주, 연락처, 고객 상담·업무일지, 개인메모, 추가메모, 임대 협의가격, 추천매물 표시, 등기부 등 일반 첨부자료. 자료에 연결된 일반 Drive 링크도 공유하지 않습니다.

케이탑이 직접 입력한 연락처·메모·매물·고객 자료는 케이탑 프로젝트 `enefadyhmhfphtochlku`에만 저장됩니다. 공유 원본을 수정/삭제하지 않습니다. 기본자료에 케이탑 메모를 저장할 때는 개인정보가 제거된 기본자료의 케이탑 사본을 먼저 만들고, 케이탑에만 변경을 저장합니다. 해당 사본이 있는 경우 케이탑 자료가 우선 표시됩니다. 공유 원본의 평면도·카테고리 변경/삭제는 읽기 전용으로 차단합니다.

## 서버 경계

하이탑 프로젝트 `xaxbkdnrzsghsabkdvzj`의 `shared-reference-data` Edge Function이 허용한 기본자료 7개 테이블만 읽습니다. 결과는 최상위·중첩 JSON 필드 허용목록으로 재구성합니다. 고객·일지 테이블은 함수에서 조회할 수 없습니다.

케이탑 JWT는 케이탑 Auth 서버의 `/auth/v1/user`로 검증하며, 확인된 이메일의 활성 `office_members` 행을 동일 JWT/RLS로 다시 확인합니다. 외부 프로젝트 JWT를 사용하므로 플랫폼 `verify_jwt`는 끄고 함수에서 인증·회원 검증을 수행합니다. JWT를 디코딩하는 것만으로 접근을 허용하지 않습니다. 서버 서비스 키는 플랫폼 환경변수에서만 읽으며 브라우저/저장소에 포함하지 않습니다.
