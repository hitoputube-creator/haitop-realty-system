# 소유 구분 조회

필지의 지번주소를 법정동코드와 PNU로 변환하고 브이월드 토지임야정보 API에서 소유구분명과 자료 기준일만 가져온다. 개인·법인 외의 구분은 기타로 표시한다. 소유자 성명, 주민등록번호, 잔금 여부는 수집하거나 추정하지 않는다.

## 서버 설정

Supabase 프로젝트의 Edge Function Secrets에 다음 설정을 등록한다. 키를 HTML, 브라우저 저장소, GitHub에 넣지 않는다.

- `VWORLD_API_KEY`: 브이월드 인증키. 토지임야정보(`ladfrlList`) 조회 권한과 이용 도메인을 확인한다.
- `VWORLD_DOMAIN`: 인증키에 등록한 도메인. 기본값 `https://hitoputube-creator.github.io`.
- `LEGAL_DONG_CODE_API_KEY`: 기존 건축물대장 조회에서 사용하는 법정동코드 조회키.

공식 API 레퍼런스: https://www.vworld.kr/dtna/dtna_apiSvcFc_s001.do?apiNum=128

함수는 JWT 검증과 `public.is_admin()` 권한 검사를 모두 적용한다. 인증키가 없으면 조회 전에 중단하며 기존 기록을 변경하지 않는다.

## 저장과 표시

기존 `land_parcels.data`에 `ownershipCheck`, `ownershipCheckAttempt`, `ownershipSnapshot`을 저장한다. 수동 입력한 소유주·연락처·금액은 유지한다. 전체 블럭을 조회하며 화면의 필터는 조회 대상을 제한하지 않는다. 유효한 지번주소가 없는 필지는 건너뛴 수를 표시한다.

조회 실패 시 기존 성공 자료를 유지한다. 중지·조회 실패·저장 실패가 있으면 전체 완료 날짜를 갱신하지 않는다. 성공적으로 저장된 일부 결과는 유지하며 이후 일부 저장 여부를 표시한다. 주소가 수정되면 이전 주소의 결과를 미확인으로 표시한다.

지도 상단의 소유 구분 보기는 저장된 자료만 표시한다. 업데이트 버튼을 눌렀을 때만 외부 조회한다.
